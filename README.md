# 🏥 Dashboards para Saúde Pública

Este repositório documenta minha experiência no desenvolvimento de **58 painéis interativos** para a gestão da regulação em saúde na Prefeitura de Contagem.

## 📊 Visão Geral
Criei estes dashboards para apoiar a tomada de decisão na gestão de filas de espera, vagas e indicadores de desempenho do SUS.

## 🗂️ Categorias de Dashboards

### Gestão de Filas
- Fila de espera por especialidade
- Pendências por distrito sanitário
- Tempo médio de espera

### Gestão de Vagas
- Consolidador de vagas livres/bloqueadas
- Agendamentos por unidade
- Ocupação por região

### Indicadores de Desempenho
- Produtividade por profissional
- Custo por atendimento
- Satisfação do usuário

### Ferramentas Administrativas
- Painel da Ouvidoria
- Censo populacional (IBGE)
- Contatos e recursos

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Visualização:** Chart.js, Google Charts
- **Dados:** Google Sheets API, MySQL
- **Design:** Responsivo, acessível, com foco em UX

## 📈 Destaque
- **58 dashboards** desenvolvidos
- **15 anos** de experiência no setor
- **Integração em tempo real** com fontes de dados oficiais
